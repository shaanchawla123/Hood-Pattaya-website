HOOD Pattaya website starter
============================

Files
- index.html: responsive single-page website starter.

IMPORTANT BEFORE PUBLISHING
1. Confirm that https://www.booking.com/hotel/th/hood-hostel.html is the correct Booking.com listing for your property.
2. Replace the generic hero image with an authentic HOOD Pattaya property photo (with permission). The current image is illustrative stock photography.
3. Replace the room-photo placeholder with real property photos.
4. Confirm the official property address, room types, capacity, facilities, rates, check-in/out times, cancellation rules, contact details, and payment methods.
5. Create a Google Form for direct booking requests at https://forms.google.com/. Copy its public responder link and replace the direct-request button's href in index.html.
6. For direct bookings, treat form submissions as requests only. Confirm availability and price manually before asking for payment. Never collect card details in Google Forms.
7. Add a privacy notice explaining what guest information is collected and how it is used.

FREE PUBLISHING OPTION: GitHub Pages
1. Sign in or create a free GitHub account at https://github.com/
2. Create a new public repository named hood-pattaya-website.
3. Upload index.html to the repository's root.
4. Open Settings > Pages.
5. Under Build and deployment, select Deploy from a branch; choose main and /(root), then Save.
6. Wait for the Pages URL shown in Settings > Pages. Test it on mobile and desktop.
7. After any edits, commit the changes and allow Pages to redeploy.

FREE GOOGLE SITES ALTERNATIVE
Use https://sites.google.com/ and create a blank site. Google Sites is easier for no-code editing, but this HTML file cannot simply be imported as a complete editable Google Sites website. Rebuild the sections in Sites, then use Publish. Public site URL will be a sites.google.com address.

LIMITATIONS
- This starter is a front-end website only. It does not maintain room inventory, synchronize OTA calendars, confirm bookings automatically, or process payments.
- External booking link is based on a public listing found during research; verify ownership before using it.
- GitHub Pages is free static hosting for a public repository. Do not put guest information or private credentials in the repository.
